HIMANSHU KUSHWAH — PORTFOLIO

Files:
- index.html: portfolio content and page structure
- style.css: responsive visual design
- script.js: navigation and dynamic profile details
- config.js: name, email, LinkedIn URL, experience and location

Preview locally:
1. Extract the ZIP file.
2. Open index.html in a modern browser.
3. Internet access is required to load the Google Fonts; the page still works without them.

Personal details:
Edit config.js to update your email, LinkedIn URL, name or experience label.

Deployment:
Upload all five files to the same folder on GitHub Pages, Netlify, or your web host.

Notes:
- The site is a static portfolio; no backend or build step is required.
- The Java section is intentionally described as current learning/development, not professional Java experience.
- Review the experience duration and all project descriptions before publishing to ensure they remain current and accurate.
